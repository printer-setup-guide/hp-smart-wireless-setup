LaserJet Setup FAQ

How do I fix a Windows Print Spooler error?

Press Windows Key + R, type 'services.msc', and press Enter. Locate 'Print Spooler' in the list, right-click, and select 'Restart'. If the error persists, you may need to clear the local spooler folder in Windows System32.

Why is my LaserJet printing blank pages?

This usually indicates that the protective sealing tape was not fully removed from the new toner cartridge before installation. Remove the cartridge, pull the orange tab completely out, and reinstall.
